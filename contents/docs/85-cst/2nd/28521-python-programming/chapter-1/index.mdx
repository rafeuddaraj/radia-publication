# অধ্যায় ১: BASIC OF PROGRAMMING

## ১.১ Computer Programming কী?

কম্পিউটার প্রোগ্রামিং হলো কম্পিউটারকে নির্দিষ্ট কাজ করতে নির্দেশ দেওয়ার একটি প্রক্রিয়া। এটি বিভিন্ন নির্দেশনার (instructions) একটি সেট, যা কম্পিউটার বুঝতে পারে এবং সেই অনুযায়ী কাজ সম্পন্ন করতে পারে।

উদাহরণস্বরূপ, যদি আমরা কম্পিউটারকে বলি যে "একটি সংখ্যা যোগ কর এবং ফলাফল দেখাও", তাহলে এটি একটি প্রোগ্রাম। এই প্রোগ্রাম লিখতে আমাদের প্রোগ্রামিং ভাষা ব্যবহার করতে হয়।

### কম্পিউটার প্রোগ্রামিং কেন গুরুত্বপূর্ণ?

1. জটিল সমস্যার সমাধান সহজে করা যায়।
2. স্বয়ংক্রিয়ভাবে বিভিন্ন কাজ করা সম্ভব।
3. ওয়েব ডেভেলপমেন্ট, গেম ডেভেলপমেন্ট, ডেটা অ্যানালাইসিস ইত্যাদি ক্ষেত্রে এটি অপরিহার্য।

## ১.২ Programming Language এবং এর শ্রেণিবিভাগ

### Programming Language কী?

প্রোগ্রামিং ভাষা হলো এমন একটি মাধ্যম, যা ব্যবহার করে আমরা কম্পিউটারের সঙ্গে যোগাযোগ করি এবং তাকে কাজ করার নির্দেশ দিই।

### Programming Language-এর শ্রেণিবিভাগ

প্রোগ্রামিং ভাষাকে মূলত দুইটি শ্রেণিতে ভাগ করা যায়:

1. লো লেভেল ল্যাঙ্গুয়েজ (Low-Level Language): এটি কম্পিউটারের হার্ডওয়্যারের সঙ্গে সরাসরি কাজ করে। যেমন: Machine Language, Assembly Language।

2. হাই লেভেল ল্যাঙ্গুয়েজ (High-Level Language): এটি মানুষের জন্য সহজবোধ্য এবং পড়তে ও লিখতে সুবিধাজনক। যেমন: Python, C, Java।

## ১.৩ Translator Programs

কম্পিউটার সরাসরি প্রোগ্রামিং ভাষা বুঝতে পারে না। তাই আমাদের প্রোগ্রামিং কোডকে মেশিন ভাষায় রূপান্তর করার জন্য Translator Programs ব্যবহার করতে হয়। Translator Programs তিন ধরনের:

1. Compiler: পুরো কোড একবারে রূপান্তর করে। উদাহরণ: C, Java।
2. Interpreter: কোড লাইন-বাই-লাইন রূপান্তর করে। উদাহরণ: Python।
3. Assembler: Assembly Language-কে মেশিন ভাষায় রূপান্তর করে।

## ১.৪ Algorithm এবং Flowchart কী?

### Algorithm

Algorithm হলো একটি সমস্যার সমাধান পেতে ধারাবাহিক নির্দেশনার একটি সেট। এটি খুব সহজ ভাষায় লিখিত হয়। উদাহরণ:

উদাহরণ: দুটি সংখ্যার যোগফল বের করার Algorithm:

1. Step 1: শুরু কর।
2. Step 2: প্রথম সংখ্যা নাও।
3. Step 3: দ্বিতীয় সংখ্যা নাও।
4. Step 4: দুটি সংখ্যা যোগ কর।
5. Step 5: ফলাফল দেখাও।
6. Step 6: শেষ কর।

### Flowchart

Flowchart হলো একটি চার্ট বা চিত্র, যা একটি সমস্যার সমাধান পেতে প্রক্রিয়াটি চিত্রিত করে। এটি বিভিন্ন প্রতীক (symbols) ব্যবহার করে তৈরি হয়।

Flowchart-এর সাধারণ প্রতীকসমূহ:

1. Oval: শুরু বা শেষ চিহ্নিত করতে।
2. Rectangle: কোনো প্রক্রিয়া নির্দেশ করতে।
3. Diamond: সিদ্ধান্ত গ্রহণ নির্দেশ করতে।
4. Arrow: প্রক্রিয়ার প্রবাহ নির্দেশ করতে।

---

## ১.৫ Flowchart-এর প্রতীকসমূহ এবং তাদের ব্যবহার

| প্রতীক | নাম       | ব্যবহার                                  |
| ------ | --------- | ---------------------------------------- |
| Oval   | শুরু/শেষ  | Flowchart শুরু বা শেষ চিহ্নিত করতে।      |
| Rectangle | প্রক্রিয়া | কোনো নির্দিষ্ট কাজ বা প্রক্রিয়া বোঝাতে। |
| Diamond   | সিদ্ধান্ত  | সিদ্ধান্ত গ্রহণ করতে।                    |
| Arrow     | প্রবাহপথ | প্রক্রিয়ার দিক নির্দেশ করতে।            |

## ১.৬ Algorithm এবং Flowchart তৈরি

উদাহরণ: দুটি সংখ্যার যোগফল বের করার জন্য Algorithm এবং Flowchart:

### Algorithm:

1. Step 1: শুরু কর।
2. Step 2: প্রথম সংখ্যা নাও।
3. Step 3: দ্বিতীয় সংখ্যা নাও।
4. Step 4: যোগফল বের কর।
5. Step 5: ফলাফল দেখাও।
6. Step 6: শেষ কর।

### Flowchart:

```
   [Start]
      |
   [Input Number1]
      |
   [Input Number2]
      |
   [Sum = Number1 + Number2]
      |
   [Print Sum]
      |
   [End]
```

## ১.৭ প্রোগ্রাম পরিকল্পনার প্রক্রিয়া

প্রোগ্রাম তৈরির সময় সঠিক পরিকল্পনা করা খুবই গুরুত্বপূর্ণ। এর ধাপগুলো হলো:

1. সমস্যা বোঝা: সমস্যার প্রকৃতি এবং প্রয়োজনীয়তা বোঝা।
2. Algorithm তৈরি: সমস্যার সমাধানের নির্দেশনা লিখা।
3. Flowchart তৈরি: Algorithm-এর চিত্রিত রূপ তৈরি।
4. কোডিং: Flowchart বা Algorithm অনুযায়ী প্রোগ্রামিং ভাষায় কোড লেখা।
5. ডিবাগিং: কোডে যদি কোনো ত্রুটি থাকে, সেটি খুঁজে ঠিক করা।
6. টেস্টিং: প্রোগ্রাম চালিয়ে পরীক্ষা করা।
7. ডকুমেন্টেশন: প্রোগ্রামের প্রতিটি ধাপের বিবরণ লিখা।

---

### প্রথম অধ্যায় শেষ।

এই অধ্যায়ে আমরা প্রোগ্রামিং-এর বেসিক ধারণা, Algorithm, Flowchart এবং প্রোগ্রাম পরিকল্পনা সম্পর্কে শিখেছি। পরবর্তী অধ্যায়ে আমরা পাইথনের বেসিক বিষয় নিয়ে আলোচনা করবো।
