### অধ্যায় ২: পাইথনের বেসিকস (BASICS OF PYTHON)

#### ২.১ পাইথনের বৈশিষ্ট্যসমূহ (Features of Python):
পাইথন একটি সহজ, শক্তিশালী এবং বহুল ব্যবহৃত প্রোগ্রামিং ভাষা। এটি অনেক বৈশিষ্ট্যসম্পন্ন, যেমন:

- **সহজ এবং পাঠযোগ্য**: পাইথনের সিনট্যাক্স (syntax) সাধারণ মানুষের পড়া সহজ, যার ফলে এটি শেখা সহজ। উদাহরণস্বরূপ, পাইথনের কোড ইংরেজি বাক্যের মতো সহজ।
  - উদাহরণ:
    ```python
    print("Hello, World!")
    ```
- **ওপেন সোর্স**: পাইথন একটি ওপেন সোর্স ভাষা, যা ফ্রি ডাউনলোড এবং ব্যবহার করা যায়।
- **মাল্টি-প্যারাডাইম সাপোর্ট**: পাইথন প্রোগ্রামিং প্যারাডাইম হিসেবে Object-Oriented, Procedural, এবং Functional প্রোগ্রামিং সাপোর্ট করে।
- **ইন্টারপ্রেটেড**: পাইথন কোড কম্পাইল করতে হয় না; এটি সরাসরি ইন্টারপ্রেট করে চালানো যায়। এর ফলে ডেভেলপাররা সহজেই কোড টেস্ট করতে পারে।
- **পোর্টেবল**: এক প্ল্যাটফর্মে লেখা কোড সহজে অন্য প্ল্যাটফর্মে চালানো যায়।
- **বড় লাইব্রেরি সাপোর্ট**: পাইথন স্ট্যান্ডার্ড লাইব্রেরি থেকে ডেটা প্রক্রিয়াকরণ, ওয়েব ডেভেলপমেন্ট, মেশিন লার্নিং, ডেটা সায়েন্স ইত্যাদি কাজ সহজে করা যায়।
- **ডাইনামিক টাইপিং**: পাইথনে ভ্যারিয়েবল ডেক্লেয়ার করার সময় টাইপ নির্ধারণ করতে হয় না। উদাহরণ:
  ```python
  x = 5  # এটি একটি integer
  x = "Hello"  # এখন এটি একটি string
  ```
- **বহুমুখী প্রয়োগ**: পাইথন ওয়েব ডেভেলপমেন্ট, সফটওয়্যার ডেভেলপমেন্ট, মেশিন লার্নিং, এবং আর্টিফিশিয়াল ইন্টেলিজেন্সের মতো বিভিন্ন ক্ষেত্রে ব্যবহৃত হয়।

#### ২.২ আইডেন্টিফায়ার এবং কিওয়ার্ডস (Identifiers and Keywords):

- **আইডেন্টিফায়ার**: প্রোগ্রামে ভ্যারিয়েবল, ফাংশন বা অবজেক্টের নামকরণ করতে আইডেন্টিফায়ার ব্যবহার করা হয়। এটি ইংরেজি বর্ণমালা, সংখ্যা এবং আন্ডারস্কোর (_) দিয়ে গঠিত হয়।
  - উদাহরণ: `name`, `student_id`, `_count`
  - **নিয়ম:**
    1. নাম সংখ্যা দিয়ে শুরু করা যাবে না।
    2. কিওয়ার্ড ব্যবহার করা যাবে না।
    3. স্পেস ব্যবহার করা যাবে না।
    4. বিশেষ চিহ্ন (যেমন @, $, %) ব্যবহার করা যাবে না।

- **কিওয়ার্ডস**: পাইথনে কিওয়ার্ড হলো সংরক্ষিত শব্দ, যেগুলো বিশেষ উদ্দেশ্যে ব্যবহৃত হয়।
  - উদাহরণ: `if`, `else`, `for`, `while`, `def`, `return` ইত্যাদি।
  - পাইথনে বর্তমানে ৩৫টি কিওয়ার্ড আছে। এগুলোর কোনোটি আইডেন্টিফায়ার হিসেবে ব্যবহার করা যাবে না।
  - উদাহরণ:
    ```python
    if = 5  # এটি ভুল
    count = 10  # এটি সঠিক
    ```

#### ২.৩ লাইন, ইনডেন্টেশন এবং মাল্টি-লাইন স্টেটমেন্ট (Lines, Indentation, Multi-Line Statements):

- **লাইন**: পাইথনে প্রতিটি কমান্ড নতুন লাইনে লেখা হয়। উদাহরণ:
  ```python
  name = "John"
  print(name)
  ```

- **ইনডেন্টেশন**: পাইথনে কোড ব্লক চিহ্নিত করতে ইনডেন্টেশন ব্যবহার করা হয়।
  - উদাহরণ:
    ```python
    if True:
        print("This is true")
    ```
  - ভুল উদাহরণ (ইনডেন্টেশন না থাকায় এরর হবে):
    ```python
    if True:
    print("Error")
    ```

- **মাল্টি-লাইন স্টেটমেন্ট**: যদি একটি লাইন খুব বড় হয়ে যায়, তবে `\` চিহ্ন ব্যবহার করে মাল্টি-লাইন করা যায়।
  ```python
  total = 10 + 20 + 30 + \
          40 + 50
  print(total)
  ```
  এছাড়া, ব্র্যাকেটের ভিতরে থাকলে `\` ব্যবহার না করেও মাল্টি-লাইন লেখা যায়।
  ```python
  numbers = [1, 2, 3,
             4, 5, 6]
  ```

#### ২.৪ কোটেশন এবং কমেন্টস-এর ব্যবহার (Quotations and Comments):

- **কোটেশন**: পাইথনে `''`, `""`, এবং `"""` ব্যবহার করে স্ট্রিং ডিক্লেয়ার করা হয়।
  - উদাহরণ:
    ```python
    single_quote = 'This is a single-quoted string.'
    double_quote = "This is a double-quoted string."
    multi_line = """This is a multi-line
    string."""
    ```

- **কমেন্টস**: পাইথনে `#` ব্যবহার করে সিঙ্গেল লাইন কমেন্ট এবং `"""` বা `'''` ব্যবহার করে মাল্টি-লাইন কমেন্ট লেখা হয়।
  - উদাহরণ:
    ```python
    # This is a single-line comment
    """
    This is a 
    multi-line comment
    """
    ```
  **কমেন্টসের ব্যবহার:**
    1. কোড ডকুমেন্টেশনের জন্য।
    2. কোড ডিবাগ করার সময়।
    3. প্রোগ্রামের বিশেষ নির্দেশনা বোঝানোর জন্য।

#### ২.৫ কমান্ড লাইন আর্গুমেন্টস (Command Line Arguments):

কমান্ড লাইন আর্গুমেন্ট দিয়ে প্রোগ্রামে ইনপুট দেওয়া যায়। এর জন্য `sys` লাইব্রেরি ব্যবহার করা হয়।

- **উদাহরণ:**
  ```python
  import sys
  print("Number of arguments:", len(sys.argv))
  print("Arguments:", sys.argv)
  ```
  **ব্যাখ্যা:**
  - `sys.argv` হলো একটি লিস্ট, যেখানে প্রোগ্রামের নামসহ পাস করা আর্গুমেন্ট থাকে।
  - যদি স্ক্রিপ্ট `example.py` নামে রান করা হয় `python example.py arg1 arg2`, তাহলে আউটপুট হবে:
    ```
    Number of arguments: 3
    Arguments: ['example.py', 'arg1', 'arg2']
    ```

#### উদাহরণ ভিত্তিক আলোচনা:

1. **পাইথনের সহজ সিনট্যাক্স:**
   ```python
   print("Hello, Python!")
   ```

2. **ইনডেন্টেশন ব্যবহার:**
   ```python
   x = 10
   if x > 5:
       print("x is greater than 5")
   ```

3. **মাল্টি-লাইন স্টেটমেন্ট:**
   ```python
   result = (10 + 20 + 30 + 
             40 + 50)
   print(result)
   ```

4. **কমান্ড লাইন আর্গুমেন্ট দিয়ে পাস করা:**
   ```python
   import sys
   for arg in sys.argv:
       print(arg)
   ```

এই অধ্যায়ে পাইথনের বেসিক নিয়ম, বৈশিষ্ট্য এবং এর প্রাথমিক ব্যবহার নিয়ে আলোচনা করা হয়েছে। পরবর্তী অধ্যায়গুলোতে আরও গভীরভাবে পাইথনের বিভিন্ন বিষয় ব্যাখ্যা করা হবে।
