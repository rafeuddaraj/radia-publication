
# অধ্যায় ৩: ভেরিয়েবলস এবং ডাটা টাইপস

## ৩.১ ভেরিয়েবলস কী?

প্রোগ্রামিং-এ **ভেরিয়েবলস** ব্যবহার করা হয় এমন তথ্য সংরক্ষণ করতে যা প্রোগ্রাম চলাকালীন সময়ে রেফারেন্স এবং ম্যানিপুলেট করা যেতে পারে। একটি ভেরিয়েবল একটি কনটেইনারের মতো কাজ করে যা ডেটা ধারণ করে, যেমন সংখ্যা বা টেক্সট। ভেরিয়েবলসে সংরক্ষিত ডেটা পরিবর্তন বা "ভ্যারিয়েবল" হতে পারে, যার কারণে এগুলোকে ভেরিয়েবল বলা হয়।

যেমন:

```python
x = 5
y = "Hello, World!"
```

এখানে, `x` একটি ভেরিয়েবল যা পূর্ণসংখ্যা মান `5` ধারণ করছে, এবং `y` একটি ভেরিয়েবল যা স্ট্রিং মান `"Hello, World!"` ধারণ করছে।

ভেরিয়েবলগুলি গুরুত্বপূর্ণ কারণ এগুলি প্রোগ্রামকে তথ্য সংরক্ষণ এবং প্রক্রিয়া করার সুযোগ দেয়, যা প্রোগ্রাম চলাকালীন সময়ে পরিবর্তিত হতে পারে।

## ৩.২ ভেরিয়েবল নামকরণের নিয়ম

ভেরিয়েবল তৈরি করার সময় কিছু নিয়ম অনুসরণ করা জরুরি যাতে প্রোগ্রামে ত্রুটি না হয়। এই নিয়মগুলো হল:

1. **ভেরিয়েবল নাম অবশ্যই একটি অক্ষর বা আন্ডারস্কোর দিয়ে শুরু করতে হবে:** ভেরিয়েবলের প্রথম অক্ষর অবশ্যই একটি অক্ষর (a-z, A-Z) অথবা আন্ডারস্কোর (`_`) হতে হবে।

   **যেমন:**
   ```python
   x, _x, variable1
   ```

   **অবৈধ নাম:**
   ```python
   1variable, @x
   ```

2. **ভেরিয়েবল নাম অক্ষর, সংখ্যা এবং আন্ডারস্কোরের সমন্বয়ে থাকতে পারে:** ভেরিয়েবল নামের মধ্যে সংখ্যা (0-9) এবং আন্ডারস্কোরও থাকতে পারে, তবে প্রথমে সংখ্যা আসতে পারবে না।

   **যেমন:**
   ```python
   variable_1, my_variable2
   ```

3. **কেস সেনসিটিভ:** ভেরিয়েবল নামগুলো কেস সেনসিটিভ হয়, অর্থাৎ `myVariable` এবং `myvariable` আলাদা আলাদা ভেরিয়েবল হিসেবে গণ্য হবে।

   **যেমন:**
   ```python
   myVariable = 10
   myvariable = 20
   ```

## ৩.৩ ভেরিয়েবলসে মান অ্যাসাইন করা

ভেরিয়েবলসে মান অ্যাসাইন করার জন্য সাধারণত সমকোণ চিহ্ন (`=`) ব্যবহার করা হয়। এটির মাধ্যমে আমরা ভেরিয়েবলকে একটি নির্দিষ্ট মান দিয়ে সেট করি।

যেমন:

```python
x = 10
name = "John"
is_active = True
```

এখানে, `x` ভেরিয়েবলটি পূর্ণসংখ্যা `10` ধারণ করছে, `name` ভেরিয়েবলটি স্ট্রিং `"John"` ধারণ করছে, এবং `is_active` ভেরিয়েবলটি বুলিয়ান `True` ধারণ করছে।

## ৩.৪ স্ট্যান্ডার্ড ডাটা টাইপস

ভেরিয়েবলগুলিতে বিভিন্ন ধরনের ডেটা থাকতে পারে। পাইটনে বিভিন্ন ধরনের ডেটা টাইপ রয়েছে, যা মূলত ৭টি প্রধান শ্রেণীতে বিভক্ত:

### ১. **ইন্টিজার (Integer):**

পূর্ণসংখ্যা মান যেমন 5, -3, 100। ইন্টিজার মানগুলো দশমিক ছাড়া শুধু সংখ্যার অংশ থাকে।

```python
age = 25
```

### ২. **ফ্লোট (Float):**

দশমিক সহ সংখ্যা যেমন 3.14, -0.001, 100.0। ফ্লোট সংখ্যা দশমিক সহ থাকে এবং এটি পাইন্টের পরে এক বা একাধিক ডিজিট ধারণ করতে পারে।

```python
price = 19.99
```

### ৩. **স্ট্রিং (String):**

অক্ষরের একটি সিকোয়েন্স, যেমন `"Hello"`, `"Python"`, `"123"`. এটি কোনো টেক্সট ধারণ করে। স্ট্রিং ডেটা টাইপটি সাধারণত একক বা দ্বৈত উদ্ধৃতি চিহ্নের মধ্যে লেখা হয়।

```python
greeting = "Hello, World!"
```

### ৪. **বুলিয়ান (Boolean):**

বুলিয়ান ডেটা টাইপ দুটি মান ধারণ করতে পারে: `True` অথবা `False`। এটি শর্তের ভিত্তিতে সত্য বা মিথ্যা বোঝায়।

```python
is_active = True
```

### ৫. **লিস্ট (List):**

লিস্ট হলো একাধিক আইটেম ধারণ করার জন্য একটি ডেটা স্ট্রাকচার। এতে বিভিন্ন ডেটা টাইপের মান থাকতে পারে।

```python
fruits = ["apple", "banana", "cherry"]
```

### ৬. **টিউপল (Tuple):**

টিউপলও একটি ডেটা স্ট্রাকচার, তবে এটি অপরিবর্তনীয়, অর্থাৎ একবার টিউপলে মান রাখা হলে সেটি পরিবর্তন করা যায় না। টিউপলটি সাধারণত কোষ্ঠক চিহ্নের মধ্যে থাকে।

```python
coordinates = (10, 20)
```

### ৭. **ডিকশনারি (Dictionary):**

ডিকশনারি হলো একটি ডেটা স্ট্রাকচার যেখানে কী (key) এবং মান (value) এর সমন্বয়ে ডেটা সংরক্ষিত থাকে। এটি ব্যবহার করে আপনি কোনো ডেটাকে দ্রুত অ্যাক্সেস করতে পারেন।

```python
person = {"name": "John", "age": 25}
```

### ৮. **সেট (Set):**

সেট হলো একটি অর্ডারহীন এবং অনন্য উপাদান ধারণকারী ডেটা স্ট্রাকচার। সেটের মধ্যে কোনো উপাদান একাধিকবার থাকতে পারে না।

```python
fruits_set = {"apple", "banana", "cherry"}
```

### ৯. **ফ্রিজ সেট (Frozen Set):**

ফ্রোজেন সেট হলো সেটের মতোই, তবে এটি অপরিবর্তনীয়। একবার ফ্রোজেন সেটে মান যুক্ত করা হলে, তা পরিবর্তন করা যায় না।

```python
frozen_fruits = frozenset(["apple", "banana", "cherry"])
```

### ১০. **নান (None):**

এটি একটি বিশেষ মান যা কিছু না থাকা বা কিছু নির্ধারিত না হওয়া বোঝায়। এটি পাইটনে একটি স্ট্যান্ডার্ড ডেটা টাইপ।

```python
x = None
```

## ৩.৫ ডাটা টাইপ কনভার্সন

একটি ডাটা টাইপ থেকে অন্য ডাটা টাইপে রূপান্তর করতে পাইটনে কিছু ফাংশন ব্যবহার করা হয়, যেমন `int()`, `float()`, `str()` ইত্যাদি।

### উদাহরণ:

```python
x = "10"   # এটি একটি স্ট্রিং
y = int(x) # স্ট্রিং থেকে পূর্ণসংখ্যায় কনভার্ট
print(y)   # আউটপুট হবে: 10
```

এখানে, `"10"` (স্ট্রিং) কে `int()` ফাংশন দিয়ে পূর্ণসংখ্যায় রূপান্তর করা হয়েছে।

## ৩.৬ একাধিক ভেরিয়েবল ব্যবহার করে প্রোগ্রাম লেখা

অনেক সময় একাধিক ভেরিয়েবল ব্যবহার করে একটি প্রোগ্রাম তৈরি করতে হয়। নিচে একটি উদাহরণ দেওয়া হলো:

### উদাহরণ:
```python
# দুটি ভেরিয়েবল যুক্ত করা
num1 = 10
num2 = 20
result = num1 + num2
print("যোগফল:", result)

# দুটি ভেরিয়েবল নিয়ে স্ট্রিং কনক্যাটেনেশন
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print("পূর্ণ নাম:", full_name)
```
